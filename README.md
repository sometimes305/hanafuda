# 花札 こいこい

スマホ縦持ち向け、2人用オンライン花札です。TierGame と同じく静的 HTML/CSS/JavaScript だけで動き、Gravity SDK でルームを管理し、PeerJS で対局状態を同期します。

進行と得点は任天堂の「こいこい」ルールに合わせています。場札・手札を八枚ずつ配り、配札時の「手四」「くっつき」は6文、出来役の合計が7文以上なら倍付け、相手のこいこい後に上がればこいこい返しでさらに倍付けします。札切れで双方に役がなければ0文のノーゲームとして親を交代し、上がった人が次の親になります。標準は十二局ですが、短時間用に三局・六局も選択できます。

## 起動

ローカル確認はこのフォルダで静的サーバーを起動し、`index.html` を開いてください。

```powershell
python -m http.server 4173
```

通常ブラウザでは「ひとりで試す」で CPU 対戦ができます。Gravity 環境では部屋作成・参加を使って2人対戦できます。

対局中は相手の手札の下と自分の手札の上に、双方の取札が常時表示されます。取札は「光・たね・短冊・かす」の定位置にまとまり、札の縁が見えるよう少しずつ横へずらして重なります。取った札も該当する種類の列へ移動します。自分と相手の取札欄には、公開されている札から判定した成立役とリーチ中の役名を表示します。

一局目の前に裏向きの札を三枚並べ、二人が順に一枚ずつ選びます。選んだ二枚を表に返し、より早い月を引いた側を先攻として名前と共に大きく表示します。札面は表に返すまで相手の端末へ送られません。各局の開始時は、山札から場へ二枚・親から見た相手へ二枚・親へ二枚の順で四回配る動きを表示してから操作を開始します。

盤面には枚数表示を省いた山札を表示します。自分の番には取れる手札と対応する場札が強調され、対応札がない手札は実際の空き位置へ直接置かれます。スマホでは手札を一度タップして選択し、同じ手札をもう一度タップするか、取りたい場札を直接タップして確定できます。山札からめくった札も、対応する場札をタップして取れます。場札は常に4列のグリッドへ一枚ずつ配置し、枚数が変わっても列を崩しません。対応札がある場合は、手札・山札のどちらから出た札も対象札の右下へ、札幅の20%ずつ横・縦にずらして一時的に重なります。手札から場への移動は0.7秒、着地後の間は0.2秒です。山札から場への移動は0.5秒、場から取札欄への移動は0.7秒で、どちらも着地後に0.1秒止めます。対応する同月札への場内移動は0.3秒、着地後の間は0.1秒です。山札は表裏を持つ一枚の札として0.3秒で180度返し、0.1秒見せてから次へ進みます。各局の配札は山札の最上面に札を重ね、そこから場・親から見た相手・親の順へ二枚ずつ運びます。場札・取札の並び直しは0.5秒です。札の移動には緩やかな減速カーブを共通で使い、終盤だけほぼ停止したように進む動きを避けます。AIやオンライン相手の札も同じ呼吸で動き、相手の操作中は案内を「相手の番」に固定します。先攻決めでは札の裏面と表面を一体で180度回転させ、途中で面が飛び替わらないようにします。役成立時は盤面を見せたまま、両者に役名と文数の帯を横からスライド表示します。その後、成立者だけに画面下部で「こいこい／上がり」を提示し、選択結果も両者へ帯で同期します。最終結果からは「タイトルに戻る」でロビーへ戻ります。勝利は金、敗北は墨と銀灰の専用演出で知らせます。PCでは端末の「視差効果を減らす」設定に応じて回転や粒子を省いた直線モーションへ切り替えます。スマホでは端末やWebViewの視差軽減判定よりゲーム側の通常テンポを全アニメーションで優先します。読み込み時には公開中の最新版を確認し、古いHTMLがキャッシュされていれば最新版のURLへ自動更新します。

## ファイル

- `index.html`: ロビーと対局画面
- `style.css`: 縦画面レイアウトと札の意匠
- `cards.js`: 48枚の札データ
- `app.js`: こいこい進行、役判定、CPU対戦、保存
- `online.js`: Gravity / PeerJS 同期
- `assets/`: 盤面背景と標準柄の札画像

## 札画像

札面と札裏は標準的な京都系花札の48枚セットを使用しています。画像の作者・ライセンスは [`ATTRIBUTION.md`](ATTRIBUTION.md) を参照してください。
