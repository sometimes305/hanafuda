# 花札 こいこい

スマホ縦持ち向け、2人用オンライン花札です。TierGame と同じく静的 HTML/CSS/JavaScript だけで動き、Gravity SDK でルームを管理し、PeerJS で対局状態を同期します。

## 公開版

<https://sometimes305.github.io/hanafuda/>

GitHub Pages の `main` ブランチ直下から配信します。

## 起動

ローカル確認はこのフォルダで静的サーバーを起動し、`index.html` を開いてください。

```powershell
python -m http.server 4173
```

通常ブラウザでは「ひとりで試す」で CPU 対戦ができます。Gravity 環境では部屋作成・参加を使って2人対戦できます。

対局中は相手の手札の下と自分の手札の上に、双方の取札が常時表示されます。取札は「光・たね・短冊・かす」の定位置にまとまり、札の縁が見えるよう少しずつ横へずらして重なります。取った札も該当する種類の列へ移動します。自分側には成立中の役と、あとどの札で役になるかも表示されます。

盤面には残り枚数つきの山札を表示します。自分の番には取れる手札と対応する場札が強調され、対応札がない手札は中央を経由せず実際の空き位置へ置かれます。対応札がある場合は、手札・山札のどちらから出た札も対象札の右下へ、札幅の20%ずつ横・縦にずらして重なります。手札は約0.9秒かけて場へ運び、着地後に約0.56秒静止します。山札は約3秒の中で、表に返して約0.78秒見せ、場へ運んで約0.48秒止めます。取った札は透明化せず、場から自分／相手の取札欄へ約1.5秒かけてゆったり移動し、着地後に約0.65秒の間を置きます。重なりを選ぶ場面にも確定後約0.48秒の間が入り、各動作を見届けてから次へ進みます。AIやオンライン相手の札も同じ呼吸で動き、同月札を選んでいる間は出した札を場に残します。取得後の場札・手札・取札の詰め直しも旧位置から新位置へ滑らせるため、対局中に札が瞬間移動する経路はありません。役成立時は両者に役名と文数のカットインを出し、成立者だけに「こいこい／上がり」を提示した後、選択結果を両者へカットイン表示します。勝利は金、敗北は墨と銀灰の専用演出で知らせます。端末の「視差効果を減らす」設定では、回転や粒子を省きつつ、札の移動関係を失わない約0.65〜1.7秒の直線モーションと短い間に切り替わります。

## ファイル

- `index.html`: ロビーと対局画面
- `style.css`: 縦画面レイアウトと札の意匠
- `cards.js`: 48枚の札データ
- `app.js`: こいこい進行、役判定、CPU対戦、保存
- `online.js`: Gravity / PeerJS 同期
- `assets/`: 盤面背景と標準柄の札画像

## 札画像

札面と札裏は標準的な京都系花札の48枚セットを使用しています。画像の作者・ライセンスは [`ATTRIBUTION.md`](ATTRIBUTION.md) を参照してください。
