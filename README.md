# 花札 こいこい

スマホ縦持ち向け、2人用オンライン花札です。TierGame と同じく静的 HTML/CSS/JavaScript だけで動き、Gravity SDK でルームを管理し、PeerJS で対局状態を同期します。

## 公開版

<https://sometimes305.github.io/hanafuda/>

GitHub Pages の `main` ブランチ直下から配信します。

## 起動

ローカル確認はこのフォルダで静的サーバーを起動し、`index.html` を開いてください。

```powershell
python -m http.server 4173
```

通常ブラウザでは「ひとりで試す」で CPU 対戦ができます。Gravity 環境では部屋作成・参加を使って2人対戦できます。

対局中は相手の手札の下と自分の手札の上に、双方の取札が常時表示されます。取札は「光・たね・短冊・かす」の定位置にまとまり、札の縁が見えるよう少しずつ横へずらして重なります。取った札も該当する種類の列へ移動します。自分側には成立中の役と、あとどの札で役になるかも表示されます。

盤面には残り枚数つきの山札を表示します。自分の番には取れる手札と対応する場札が強調され、対応札がない手札は中央を経由せず実際の空き位置へ置かれます。対応札がある場合は、手札・山札のどちらから出た札も対象札の右下へ、札幅の20%ずつ横・縦にずらして重なります。山札は約1.8秒かけてその場で表向きにめくり、札名を見せた後、対応する場札または空き位置へ移動します。取った札は透明化せず、場から自分／相手の取札欄へ約1.1秒かけてゆったり移動して重なります。AIやオンライン相手の札も伏せ札の位置から表向きになって場へ移動し、同月札を選んでいる間は出した札を場に残します。取得後の場札・手札・取札の詰め直しも旧位置から新位置へ滑らせるため、対局中に札が瞬間移動する経路はありません。役成立時は両者に役名と文数のカットインを出し、成立者だけに「こいこい／上がり」を提示した後、選択結果を両者へカットイン表示します。勝利は金、敗北は墨と銀灰の専用演出で知らせます。端末の「視差効果を減らす」設定では、移動関係を失わない短い直線モーションに切り替わります。

## ファイル

- `index.html`: ロビーと対局画面
- `style.css`: 縦画面レイアウトと札の意匠
- `cards.js`: 48枚の札データ
- `app.js`: こいこい進行、役判定、CPU対戦、保存
- `online.js`: Gravity / PeerJS 同期
- `assets/`: 盤面背景と標準柄の札画像

## 札画像

札面と札裏は標準的な京都系花札の48枚セットを使用しています。画像の作者・ライセンスは [`ATTRIBUTION.md`](ATTRIBUTION.md) を参照してください。
